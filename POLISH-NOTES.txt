Cloudflare Turnstile
--------------------
Turnstile is NOT enabled in this package because the public Site Key has not been supplied and the private Secret Key must never be committed to the website. Formspree supports Turnstile directly.

Recommended setup:
1. Create a Turnstile widget in Cloudflare for ralphiestudios.com (Managed mode is a good default).
2. In Formspree, open the WRL form settings > CAPTCHA, choose Cloudflare Turnstile, and enter the Turnstile SECRET KEY there.
3. Add the public SITE KEY to the WRL form markup. The secret key must remain in Formspree/Cloudflare only.
4. Test a real submission and a failed/blocked submission before deploying.

Once the Site Key is available, the WRL form can be wired to Turnstile in a very small HTML change.
